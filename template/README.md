# Your Folio site

`npm install`, then `npm run dev`. Open `/edit/` to edit. `npm run build` generates `dist/`.

Set your name and canonical URL in `folio.config.json`; choose `neutral` or `paper90`. The page inspector can override the theme per page. Keep draft/noindex on until your content is ready.

Deploy to Netlify with `netlify.toml`. The local editor is excluded from the deployed site.
